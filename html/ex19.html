FORM 태그

- 사용자가 입력한 데이터를 서버로 전달하는 영역을 만드는 태그
- form 태그 안에 input, select, textarea 등 모든 입력 요소가 들어감
- 전송 방법 method 속성
- 어디로 보낼것인지 action 속성

form 태그의 내부 요소는 name="값" 쌍으로 전달됨

name 속성이 key, value 속성이 value 역할.
name 속성은 절대 중복되면 안됨

input 태그

- form 에서 가장 중요한 태그
- input 은 단일(싱글)태그 : 종료태그 없음

다양한 type들

text 한 줄 텍스트 입력
password 비밀번호 입력(**** 처리)
radio 단일 선택
checkbox 다중 선택
button 클릭 버튼
submit 전송 버튼
reset 초기화
hidden 사용자에게 보이지 않지만 서버로 값 보냄
file 파일 업로드

button 태그

- input 보다 유연성 및 기능 확장이 가능해서 많이 사용됨
- javascript에서 활용 많이 됨

submit, reset 속성

- form 태그 내부에서만 동작하는 버튼
submit form 데이터를 전송
reset form 입력값 전체 초기화

SELECT, OPTION 태그 - 사용자에게 선택 목록 제공
- 드롭다운 목록 생성

주요 속성

- size : 한번에 보여줄 항목 수
- selected : 기본 선택값 지정

TEXTAREA 태그

- 여러줄 텍스트 입력할 때 사용

주요 속성

- rows, cols 길이 지정

FORM 전송 방식 method

- GET : 주소(URL)에 데이터 포함
- POST : 주소에 데이터를 노출하지 않음

action 속성

입력한 데이터를 처리할 페이지(URL) 지정
데이터를 보내려면 반드시 action과 method가 있어야 함
