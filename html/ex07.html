특수문자

일종의 기호 문자이며 두가지 기능을 위하여 사용

1. < : < > : > <head> :

왼쪽 꺽쇠(<) 태그의 시작, 오른쪽 꺽쇠(>) 태그의 종료 의미
앤드&기호는 특수문자의 시작 의미
HTML 문서에서 특수한 의미를 지님. 일반 문서에서는 사용 불가

2. 일반적으로 문서 편집기에 없는 문자를 표현하기 위해 사용


큰따옴표(") : "큰따옴표 사용 테스트"

문자들을 HTML 문서에서 사용하려면 그 문자들의 문자기호(escape 기능)를 사용해야 한다.

< ; 혹은 < : < 의 문자 기호 > ; 혹은 > : > 의 문자 기호
& 혹은 & : &의 문자 기호
  혹은   : 공백의 문자 기호
© 혹은 © : 저작권 문자 기호
∫ 혹은 ∫ : 인테그랄
∑ 혹은 ∑ : 합계

일반적으로 대소문자를 구별하지 않는 HTML과 달리
특수문자나 문자기호들은 대소문자를 구별.
Å 과 å 은 다르다.
*AElig; 과 æ 은 다르다
