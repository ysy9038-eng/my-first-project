FONT 태그

글자의 표현 형태(스타일)를 나타내며
여러가지 속성/속성값(속성 : attribute)을 가진다.
명령 요소(태그) - element
속성 - attribute

FONT 태그에서 사용할 수 있는 속성

- size, color, face
폰트 크기 1에서 7사이의 정수
7이 가장 크고, 1이 가장 작다.

7777
6666
5555
4444
3333
2222
1111

폰트 색상 - 색상값에는 색상명이나 색상번호를 넣음
색상 번호는 빨강R 초록G 파랑B rrggbb 색상의 정도를 16진수로 표현한 것
높은 값은 ff, 낮은 값은 00 으로 표시
색상명은 기억하기 좋은 영문으로 미리 정한 값
rgb 색상표를 검색하여 사용

ff0000
cccccc
gold
skyblue

폰트 모양 - 글꼴을 지정
글꼴표(font face)를 참조
-font face가 표현되지 않는것도 있다
궁서
바탕>
Comic Sans Ms
Impact


굴림굴림굴림
- 속성들을 조합하여 사용
FONT size="6" face="궁서" color="008000"
FONT size="3" color="fusia" face="바탕"
속성값을 큰따옴표("")로 묶어주는것이 원칙! 생략도 가능
속성 값에 띄어쓰기가 있을 경우 반드시 큰따옴표 사용
