글자들을 표현하는 태그들

라인모드(line mode)와 블럭모드(block mode)

라인 모드 : 줄바꿈을 자동적으로 적용하지 않음

블럭 모드 : 줄바꿈을 자동적으로 적용, 여러줄의 문장을 표현하기 위함.


라인모드

B태그, STRONG태그
- 태그 안에 글자를 굵게 강조 표시

문장 중에 굵게 표시되는 내용
강조 표시 되는 내용

I 태그, CITE 태그, DFN 태그, EM태그
- 태그 안의 글자를 기울인 이태릭 글자로 표시.
이태릭 글자로 표시되는 내용
CITE 글자로 표시되는 내용
DFN 글자로 표시되는 내용
EM 글자로 표시되는 내용

U태그, INS태그
- 태그 안의 글자를 지운 글자로 표시
지운 글자로 표시되는 내용
밑줄이 들어간 글자로 표시되는 내용
줄친 글자로 표시되는 내용
줄친 글자로 표시되는 내용

블럭 모드

p 태그
- 태그 안의 문장을 하나의 문단으로 표시.
- 시작과 끝(P태그의 위/아래)에 빈 줄을 삽입하면서 자동 줄바꿈 적용
문장 중에서

하나의 P문단 표시

이런식으로 적용 됨.

ADDRESS 태그
- 태그 안의 문장을 이태릭체로 표현하는 하나의 문단으로 표시.
- 시작과 끝에 자동 줄바꿈 적용, 빈 줄을 삽입하지는 않음.
문장 중에서
하나의 ADDRESS 문단 표시
이런식으로 적용 됨.


PRE 태그
- 태그 안의 문장을 하나의 문단으로 표시
- 시작과 끝에 자동 줄바꿈 적용, 빈 줄을 삽입
- 빈 칸, 줄바꿈, 탭(tab)을 그대로 표현
문장 중에서 
하나의 PRE 문단 표시
	줄바꿈 표현, 탭 표현.
이런식으로 적용 됨.


DIV 태그
- 태그 안의 문장을 하나의 문단으로 표시
- 시작과 끝에 자동 줄바꿈 적용, 빈줄을 삽입하지 않음
문장 중에서
하나의 DIV 문단 표시
이런식으로 적용 됨.
