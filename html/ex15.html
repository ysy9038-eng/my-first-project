TABLE 태그

- 표(table)를 만들 때 사용. 포함하는 요소 3가지
- 표의 줄 : TR( Table Rows )
- 표의 칸 : TD( Table Data )
- 표의 제목 : TH( Table Title )

TABLE 에서 사용하는 속성

bgcolor = 색상 표의 바탕색을 색상값으로 지정
width = 길이 표의 너비를 픽셀 or 백분율 지정
border = 두께 표의 테두리 두께 지정
cellspacing = 칸(cell) 사이의 간격(여백)을 지정
cellpadding = 칸 내부의 간격(여백)을 지정
TR 태그 - 표의 줄 태그
- TABLE 태그 내에서 반드시 한쌍이 존재해야 함

TR 태그의 속성

bgcolor = 색상 줄의 바탕색을 색상값으로 지정
width = 가로길이 줄의 폭을 지정
height = 세로길이 줄의 높이 지정
align = left | center | right
줄에서 내용의 수평 정렬을 지정
valign = top | middle | bottom
줄에서 내용의 수직 정렬을 지정

브라우저에 따라 표현의 차이가 있음

TH 태그와 TD 태그

- 표의 제목 요소도 표의 칸의 한 종류
- 속성들도 거의 같음

TD 태그의 속성

bgcolor = 색상 칸의 바탕색을 지정
background = URL 칸의 배경이미지를 URL로 지정
width = 가로 칸의 폭을 지정
height = 세로 칸의 높이 지정
align = left | center | right
칸 내용의 수평 정렬을 지정. 기본값 left
valign = top | middle | bottom
칸 내용의 수직 정렬을 지정. 기본값 middle
colspan = 갯수 해당 칸에서 사용할 가로 통합 칸의 갯수 지정
rowspan = 갯수 해당 칸에서 사용할 세로 통합 칸의 갯수 지정

브라우저에 따라 표현의 차이가 있음
