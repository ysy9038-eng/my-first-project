A 태그

- 문서나 이미지를 HTML 상에서 불러 표현하기 위해서는 해당 파일을 지정해야 함
이때 앵커태그를 사용함.

name
- 현재 A가 다른 연결과 구분되도록 이름을 지정하는 것.
- 부위 지정에 사용

href="URL"
- 웹 안에서 위치를 지정하여 연결시킴.

네이버

부위 지정

< A name="top" > 문서 맨 위(BODY 바로 아래) 에 작성,
< A name="bottom" > 문서 맨 아래(BODY 종료 바로 위) 에 작성
맨위로 맨아래로 누르면 이동!
