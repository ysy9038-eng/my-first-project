웹 사이트 방문자에게 정보와 서비스를 제공하는 공간 ip 주소 : 컴퓨터를 구분하는 고유 숫자 도메인 : 사람이 기억하기 쉬운 주소 ( naver.com, google.com, .. ) DNS 서버 : 도메인 -> IP 주소 변환 HTTP / HTTPS 프로토콜 HTTP (HyperText Transfer Protocol) : 웹페이지를 주고받는 약속 (보안 없음) 가볍고 빠르지만 엿보기 가능 HTTPS (HyperText Transfer Protocol Secure) : 보안을 추가한 HTTP (암호화) 데이터 암호화, 엿보기 불가 서버 / 클라이언트 클라이언트 : 요청하는 쪽 (웹 브라우저) 서버 : 요청을 처리하고 응답하는 쪽 웹 개발 기본 언어 HTML : 웹 페이지의 기본 뼈대 CSS : 디자인 요소 JavaScript : 이벤트 처리 기능 HTML ( HyperText Markup Language ) HyperText : 서로 연결된 텍스트 의미 웹 페이지에서 링크를 통해 다른 문서로 이동할 수 있는 기능 Markup Language : 데이터를 구조화하고 웹 페이지의 콘텐츠를 표시하기위해 사용되는 언어 <> HTML에서는 태그를 사용해 문서의 구조를 정의. HTML 의 태그 < 와 > 로 감싸져 있는 것들을 말함. <..> 시작태그와 종료태그가 있다 요소(element)라는 명령 내용과 이 요소가 가지는 속성(attribute), 속성값이 들어간다 싱글 태그 : 종료태그가 없는 태그
