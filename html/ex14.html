HTML 문서의 목록

- 상위와 하위가 있는 체계화된 목록을 만들 때 사용
- 정의 목록(DL : Definition List)
- 번호 없는 목록(UL : Unordered List)
- 번호 있는 목록(OL : Ordered List)

정의 목록

DL 태그

- 정의 목록의 태그
- 그 내용을 갖는 요소(element)로는
정의 목록 제목(DT : Definition Title),
정의 목록 데이터(DD : Definition Data)로 이루어져 있다.

DT 태그

- 정의 목록의 제목.
- 자동 줄바꿈 적용, 들여쓰기 적용
- 종료 태그 선택적 사용

DD 태그

- 정의 목록의 데이터
- 자동 줄바꿈 적용, 들여쓰기 적용
- 종료 태그 선택적 사용


목록 제목1
목록 내용 1-1
목록 내용 1-2
목록 제목 2
목록 내용 2-1
목록 내용 2-2

번호 없는 목록

UL 태그

- 번호 없는 목록의 태그
- 목록 항목(LI : List item)이 하위 속성으로 들어감.

LI 태그

- 목록 항목 태그
- 자동 줄바꿈 적용, 들여쓰기 적용.
- 종료 태그 선택적 사용

UL요소와 LI요소(element)에서 사용되는 속성(attribute) : type

- UL 태그에 type이 지정되는 경우 하위 태그인 LI 태그에도 적용 됨.

각 값이 어떻게 나타나는지, 기본값은 어떤지 -> 브라우저에 따라 다름


  • 값이 "disc" : 꽉 찬 원으로 표현.
  • 값이 "circle" : 원의 테두리로 표현
  • 값이 "square" : 꽉 찬 네모로 표현.

    번호 있는 목록

    OL 태그

    - 번호 있는 목록의 태그
    - 내부에 가지는 태그로는 목록 항목(LI : List Item)이 있음

    LI 태그

    - 목록 항목 태그
    - 자동 줄바꿈 적용, 들여쓰기 적용
    - 종료 태그 선택적 사용

    OL 태그와 LI 태그에서 사용되는 속성 : type

    - OL태그에 type이 지정되는 경우 하위 태그인 LI태그에도 적용됨
    - 로마숫자 대/소문자, 알파벳 대/소문자, 숫자
    - OL태그 추가 속성 : start="값"
