- 아무 속성 지정하지 않으면 자동으로 text 가 적용됨
- value="초기값 지정"

type="radio"

- 단일 선택(항상 1개만 선택 가능)
- 한 그룹안의 radio는 name이 같아야하고, value는 달라야함
- checked : 초기값 선택시 사용

type="checkbox"

- 다중 선택 가능
- 같은 name을 사용하는 경우 배열 형식으로 전달됨
- checked : 기본 선택 가능
